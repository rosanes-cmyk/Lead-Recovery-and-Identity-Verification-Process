# Quick Reference — Lead Recovery & Identity Verification

A one-page cheat sheet. See [`SOP.md`](SOP.md) for full detail.

## Time limits

| Type | Max | Authorization | Typical use |
| --- | --- | --- | --- |
| **Standard** | 30 min | — | Basic owner/phone/email/mailing verification, simple name mismatches |
| **Enhanced** | 60 min | Manager required | Multiple owners, trust/estate/probate, major identity conflicts, complex history |

When the limit is reached: **stop, document, recommend a status.**

## Ownership source order (strongest first)

1. County Assessor
2. County Recorder
3. County Tax Collector
4. County GIS / parcel viewer
5. PropertyRadar
6. DealMachine
7. Other lawful public records

> People-search sites **cannot** confirm ownership.

## People-search methods

| Method | Use when |
| --- | --- |
| By **address** | Seller name unknown, incomplete, or possibly wrong |
| By **phone** | Have a number, name missing or questionable |
| By **name** | Have a name, address/phone uncertain |
| By **email** | Tool supports reverse-email lookup |

Always cross-check against a stronger source; verify a name through at least one
additional source.

## Confidence levels

| Level | Basis |
| --- | --- |
| **High** | County/recorded/court records, direct seller confirmation, or multiple matching reliable sources |
| **Medium** | Likely correct; several details match; official confirmation still missing |
| **Low** | One weak source, a possible match, conflicts remain, or aggregator-only |

Low-confidence information is **not** verified.

## Phone classification

- **Confirmed** — seller-confirmed, or several reliable sources agree
- **Likely** — right name + matching location, not seller-confirmed
- **Possible** — one source, thin support
- **Invalid / Unrelated** — belongs to another person or confirmed wrong

## Outreach order (only if authorized in Step 2)

Call → Voicemail → Text → Email → Alternate number → Letter → Relative/connected
person (**separately authorized only**).

Never: negotiate, discuss price/offers, make promises, give legal conclusions,
allege fraud, or contact relatives without permission.

## Final statuses (choose exactly one)

| Status | When |
| --- | --- |
| **Seller Contact Located** | Correct seller identified + ≥1 usable contact method or mailing address confirmed |
| **Seller Confirmed Interested** | Outreach authorized, correct seller responded and confirmed interest |
| **No Contact After Investigation** | Time limit reached, no reliable contact confirmed, seller not located |
| **Management Review Required** | Ownership/identity conflicts, trust/estate/probate/fraud concern, multiple owners, possible relative, or material conflict with records |

## Reassignment

| Destination | When |
| --- | --- |
| **Acquisitions** | Contact located, mailing address confirmed, ready for follow-up |
| **Cherry Hombre** | Management Review Required / conflicts / trust-estate-probate-relative issues |
| **Transaction Coordination** | Lead already under contract; investigation affects an active transaction |

## Definition of Done (operator executes all four)

1. Complete note saved in REI BlackBook
2. Approved final status selected
3. Next task and due date created
4. Lead reassigned to the correct person/department
